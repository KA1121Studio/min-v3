## 1. 管理者権限について

### 管理者とは

管理者は、一般ユーザーより多くの操作権限を持つユーザーです。以下の操作が可能です。

- ルームの削除
- ユーザーの停止・再開
- 通報の確認と対処（メッセージ削除・投稿者停止）
- 管理者の追加・剥奪
- 全メッセージの削除

### 管理者の種類

| 種類 | 説明 |
|---|---|
| 一般管理者 | 通常の管理者。追加・剥奪が可能 |
| 最高管理者 | 絶対に削除・剥奪・停止できない特別アカウント。複数人存在する |

### 管理者権限の付与

管理者権限は、既存の管理者が管理画面から付与します。詳細は [7. 管理者管理](#7-管理者管理) を参照してください。

## 2. 管理画面へのアクセス

### アクセス方法

1. 管理者アカウントでログイン
2. サイドバー下部の **⚙️（歯車アイコン）** をクリック
3. 管理画面が開く

### アクセスできない場合

- ログインしているアカウントに管理者権限がない
- アカウントが停止されている（ログイン自体が拒否されます）
- ブラウザのキャッシュが古い → 再ログインを試す

### チャットへ戻る

管理画面右上の **「チャットへ戻る」** ボタンで、チャット画面に戻ります。

## 3. サマリーの確認

管理画面の最上部に、以下の統計が表示されます。

| 項目 | 内容 |
|---|---|
| 総ユーザー | 登録されている全ユーザー数 |
| ルーム数 | 存在する全ルーム数（全体・オープン・プライベート含む） |
| メッセージ | 全ルームのメッセージ総数 |

## 4. ルーム管理

### ルーム一覧の確認

「🌐 ルーム管理」カードに、全ルームが一覧表示されます。

| 表示項目 | 内容 |
|---|---|
| アイコン + ルーム名 | ルームの識別情報 |
| 種別 | 全体 / オープン / 非公開 |
| 削除ボタン | ルームを削除 |

### ルームの削除

1. 削除したいルームの **「削除」** ボタンをクリック
2. 確認モーダルで **「実行する」** をクリック
3. ルームが削除される（配下のメッセージ・メンバー・招待も連鎖削除）

**注意事項：**
- **全体チャットは削除できません**（削除ボタンが無効化されています）
- 削除は取り消せません

## 5. ユーザー管理

### ユーザー一覧の確認

「👤 ユーザー管理」カードに、全ユーザーが一覧表示されます。

| 表示項目 | 内容 |
|---|---|
| ユーザー名 | 👑 が付いているユーザーは管理者 |
| ステータス | `active`（有効） / `停止中` |
| 操作ボタン | `停止` / `再開` |

### ユーザーの停止（BAN）

1. 停止したいユーザーの **「停止」** ボタンをクリック
2. ユーザーが停止され、ステータスが「停止中」になる

**停止されたユーザーへの影響：**
- 新規ログインが拒否される（「このアカウントは停止されています」と表示）
- **既にログイン中の場合は、数秒以内に自動ログアウトされる**

### ユーザーの再開（BAN解除）

1. 停止中のユーザーの **「再開」** ボタンをクリック
2. ステータスが `active` に戻り、ログイン可能になる

**注意事項：**
- 最高管理者は停止できません（サーバー側で拒否されます）

## 6. 通報・モデレーション

### 通報一覧の確認

「🚩 通報・モデレーション」カードに、ユーザーからの通報が一覧表示されます。

| 表示項目 | 内容 |
|---|---|
| 通報者 → 投稿者 | 誰が誰を通報したか |
| 通報理由 | 通報者が入力した理由 |
| ステータス | `要対応` / `解決済み` / `却下` |

### 通報の詳細確認

1. 通報項目をクリック
2. 詳細モーダルが開き、以下が表示される

| 表示項目 | 内容 |
|---|---|
| ステータス | 現在の対応状況 |
| 通報されたメッセージ | ルーム名、メッセージ本文、投稿日時 |
| 投稿者 | 名前、**過去の通報件数**（判断材料） |
| 通報者 | 名前 |
| 通報理由 | 全文 |
| 通報日時 | 通報された日時 |

### 通報への対処

詳細モーダルの下部に、以下のボタンがあります。

| ボタン | 動作 |
|---|---|
| **メッセージ削除** | 通報されたメッセージを削除し、通報を「解決済み」にする |
| **投稿者を停止** | 投稿者のアカウントを停止し、通報を「解決済み」にする |
| **解決済みにする** | 通報を「解決済み」にする（メッセージは残す） |
| **却下** | 通報を「却下」にする（問題なしと判断） |

### 対処の流れ（推奨）

1. 通報一覧から該当の通報をクリック
2. メッセージ本文・投稿者の過去通報件数を確認
3. 以下の基準で判断：
   - **明らかな違反**（スパム、誹謗中傷）→ 「メッセージ削除」または「投稿者を停止」
   - **軽微な違反** → 「解決済みにする」（メッセージは残す）
   - **問題なし** → 「却下」
4. 判断に迷う場合は、複数の管理者で協議する

**注意事項：**
- メッセージ削除・投稿者停止は取り消せません
- 投稿者停止時は、そのユーザーが即座にログアウトされます

## 7. 管理者管理

### 管理者一覧の確認

「👑 管理者管理」カードに、現在の管理者が一覧表示されます。

| 表示項目 | 内容 |
|---|---|
| ユーザー名 | 🔒 が付いているユーザーは最高管理者 |
| ステータス | `管理者` |
| 操作ボタン | `剥奪` / `保護中`（最高管理者は無効） |

### 管理者の追加

1. 「管理者にするユーザー名」欄に、追加したいユーザー名を入力
2. **「追加」** ボタンをクリック
3. 対象ユーザーが管理者一覧に追加される

**注意事項：**
- 存在しないユーザー名を入力すると「ユーザーが見つかりません」と表示される
- 既に管理者のユーザーを指定すると「既に管理者です」と表示される
- 一般ユーザーを管理者に昇格させる操作です。信頼できるユーザーのみ追加してください

### 管理者の剥奪

1. 剥奪したい管理者の **「剥奪」** ボタンをクリック
2. そのユーザーの管理者権限が外れる

**注意事項：**
- **自分自身の管理者権限は剥奪できません**（サーバー側で拒否）
- **最高管理者は剥奪できません**（ボタンが「保護中」で無効）
- 最後の管理者を剥奪すると、管理画面にアクセスできるユーザーがいなくなります。注意してください

## 8. 危険な操作

### 全メッセージの削除

「⚠️ 危険な操作」カードの **「全メッセージを削除」** ボタンで、**全ルームの全メッセージ**を一括削除します。

1. **「全メッセージを削除」** をクリック
2. 確認モーダルで **「実行する」** をクリック
3. 全メッセージが削除される

**注意事項：**
- **この操作は取り消せません**
- 通常のモデレーションでは、個別のメッセージ削除（通報詳細から）を使用してください
- 全メッセージ削除は、テスト環境のリセットや緊急時のみ使用してください

## 9. 最高管理者について

### 最高管理者とは

最高管理者は、システムの**最上位管理者**として保護されているアカウントです。以下の操作が**すべて拒否**されます。

| 操作 | 結果 |
|---|---|
| 管理者権限の剥奪 | ❌ 拒否（「管理者権限は外せません」） |
| アカウントの停止 | ❌ 拒否（「停止できません」） |
| アカウントの削除 | ❌ 拒否（「削除できません」） |

### 最高管理者の人数

最高管理者は**複数人**存在します。現在の最高管理者は以下の通りです（システム管理者が設定）。

- `K-tube-admin`


> 最高管理者の追加・変更は、システムのコード（`server.js` の `PROTECTED_ADMIN_USERNAMES`）を編集して再デプロイする必要があります。一般の管理者が管理画面から追加することはできません。

### なぜ保護されているか

- 管理者が誤って全員の権限を外した場合でも、最高管理者で復旧できるようにするため
- 悪意のある管理者による締め出しを防ぐため
- 複数人いることで、1人のアカウントに問題が起きても復旧できる

### 注意事項

- 最高管理者のパスワードは厳重に管理してください
- パスワードを忘れると、誰も管理画面にアクセスできなくなる可能性があります
- パスワードは定期的に変更し、安全な場所に保管してください
- 最高管理者同士でパスワードを共有しないでください（個別に管理する）

## 10. トラブルシューティング

### 管理画面が開かない

| 症状 | 対処 |
|---|---|
| ⚙️をクリックしても反応しない | ログイン中のアカウントが管理者か確認。管理者でなければ「管理者権限がありません」と表示される |
| 「管理者権限がありません」と表示される | 管理者に昇格してもらうか、最高管理者でログインする |
| 画面が真っ白になる | ブラウザのConsoleにエラーが出ていないか確認。キャッシュクリア（Ctrl+Shift+R）を試す |

### ユーザーを停止したのにログアウトされない

- 停止通知はRealtimeで送信されます。ネットワーク状況により数秒かかる場合があります
- 対象ユーザーがオフラインの場合は、次回ログイン時に拒否されます
- しばらく待ってもログアウトされない場合は、対象ユーザーに手動ログアウトを依頼してください

### 通報が表示されない

- 通報が0件の場合は「通報はありません」と表示されます
- ユーザーが通報した直後は、管理画面を再読み込み（⚙️を再度クリック）してください

### メッセージ削除・投稿者停止ができない

| 症状 | 対処 |
|---|---|
| 「メッセージが見つかりません」 | 既に削除されている可能性があります。通報一覧を再読み込みしてください |
| 「最高管理者は停止できません」 | 保護アカウントのため、仕様通りです |
| 確認モーダルが表示されない | ブラウザのConsoleにエラーが出ていないか確認してください |

### 管理者の追加ができない

| 症状 | 対処 |
|---|---|
| 「ユーザーが見つかりません」 | ユーザー名の綴りを確認。大文字小文字は区別されません |
| 「既に管理者です」 | そのユーザーは既に管理者です |
| 「管理者権限が必要です」 | ログイン中のアカウントが管理者か確認 |

| 操作 | 一般管理者 | 最高管理者 |

| 管理者剥奪 | ✅（自分以外） | ✅（最高管理者以外） |
| 全メッセージ削除 | ✅ | ✅ |
| 自分自身の剥奪 | ❌ | ❌ |
| 最高管理者の剥奪・停止・削除 | ❌ | ❌ |
